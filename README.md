# RAM Claims Portal

Submit and view RAM vehicle warranty claims.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3002

## Sign in

The portal requires login before accessing any pages:

- **Login ID:** `TestID`
- **Password:** `TestPassword`

## Deploy to Vercel

1. Import this repo on [vercel.com/new](https://vercel.com/new)
2. Add **Blob** storage so claims persist on serverless
3. Redeploy

## Claim items

- Clutch plate
- Wipers
- Tail Light
- Head light
- Tyres
- Windsheild
